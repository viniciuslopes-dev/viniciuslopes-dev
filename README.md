## Sobre mim

Sou desenvolvedor de RPA, bacharel em **Engenharia de Produção** e pós-graduado em **Gestão Estratégica de Negócios** e **SAP Integration - BTP**. Combino essa formação com desenvolvimento de software para automatizar processos de logística, exportação, crédito e gestão de dados.

Minha atuação reúne **Power Automate Desktop e Cloud, Python, SAP GUI Scripting e integração com APIs**, com foco em reduzir tarefas manuais, padronizar rotinas e disponibilizar informações para a operação.

## Soluções que desenvolvo

| Área | Aplicações |
| :--- | :--- |
| **SAP e logística** | Automação de ordens de venda e remessas, análise de atendimento com base em pedidos e estoques e geração de relatórios operacionais. |
| **Exportação e certificação** | Automação de documentação como DCPOA, CSI, CSN e declarações do MAPA; integração REST para emissão de certificados Halal e SOAP para cadastro de bookings de contêineres. |

| **Documentos e OCR** | Extração de identificadores em certificados digitalizados com Tesseract, agrupamento de páginas e geração de PDFs por certificado. |
| **APIs e planilhas** | API em FastAPI para preenchimento de modelos Excel, com integração a fluxos n8n para enriquecimento de dados. |
